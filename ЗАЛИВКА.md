# Заливка сайта на https://advokateva.ru

Хостинг REG.RU, панель ISPmanager. Архив: **`Работа elhp.iv/upload-advokateva.zip`**
(собирает `bash build.sh`; 31 файл — всё от корня сайта, включая скрытый `.htaccess`).

## 1. Перед заливкой — в ISPmanager

1. **SSL.** «SSL-сертификаты» → Let's Encrypt на `advokateva.ru` и `www.advokateva.ru`.
2. **Перенаправления — выключить в панели.** В настройках сайта `advokateva.ru` снять
   «Перенаправлять HTTP-запросы в HTTPS» и HSTS. Все перенаправления (http→https,
   www→без www, /index.html→/) делает `.htaccess` одним шагом; если включить ещё и
   панель, будет лишний шаг или петля. На advokat-dan.ru (тот же хостинг) так и сделано.

## 2. Заливка

1. «Менеджер файлов» → папка сайта `www/advokateva.ru/`.
2. Удалить заглушку хостинга (`index.html` / `index.php`, если есть).
3. «Загрузить» → `upload-advokateva.zip` → выделить архив → «Извлечь» в эту же папку.
4. Проверить, что в корне есть `index.html`, `.htaccess`, `privacy/`, `css/`, `js/`,
   `assets/`. `.htaccess` — скрытый файл: если менеджер его не показывает, включите
   показ скрытых. Сам архив после распаковки удалить (он и так закрыт `.htaccess`).

## 3. Проверка после заливки

```bash
bash tools/final-check.sh
```

Проверяет боевой домен: коды ответа, перенаправления одним шагом, robots.txt,
sitemap.xml, закрытые служебные файлы, страницу 404, заголовки кэша, страницы
в браузере, якоря направлений, Метрику (без отправки статистики), MAX, адаптив.
Отчёт — `reports/final-check/live_<дата>/report.md`.

Вручную: открыть `http://www.advokateva.ru/index.html` — должна открыться
`https://advokateva.ru/` без промежуточных шагов.

**Если браузер пишет «слишком много переадресаций»:** в `.htaccess` удалить блок
`RewriteCond %{HTTPS} =on [OR]` … `RewriteRule ^ https://advokateva.ru%{REQUEST_URI}`
(пункт «http → https и www → без www», вместе с признаками https над ним) и включить
в ISPmanager «Перенаправлять HTTP-запросы в HTTPS»; правило про `/index.html` оставить.

## 4. Яндекс Метрика

Номер счётчика **114124193** уже вписан (`METRIKA_ID` в `js/main.js`). Счётчик загружается
только после кнопки в плашке cookie, без Вебвизора, ecommerce и `<noscript>`.

В Метрике создать цели типа «JavaScript-событие»: `phone_click`, `whatsapp_click`,
`max_click`, `email_click`, `vk_click` (по желанию — `sec_<якорь>` и `open_<якорь>`
для строк направлений, список — в README).

## 5. Яндекс Вебмастер

1. Добавить сайт `https://advokateva.ru`, способ подтверждения — мета-тег.
2. Значение `content` вписать в `YANDEX_VERIFICATION` в начале `build.sh` →
   `bash build.sh` → залить `index.html` (или весь архив).
3. После подтверждения: «Индексирование» → «Файлы Sitemap» → `https://advokateva.ru/sitemap.xml`.

## Заметки

- На REG.RU статику (CSS, JS, картинки) отдаёт nginx сам — заголовки кэша из
  `.htaccess` на неё могут не действовать (на advokat-dan.ru nginx ставит 30–45 дней).
  Это нормально: у CSS и JS в адресе `?v=` по содержимому.
- HSTS в `.htaccess` закомментирован — включить, когда https на домене проверен.
- Демо на GitHub Pages (`bash tools/publish-pages.sh`) работает и после смены домена:
  скрипт сам подменяет адреса на Pages и закрывает демо от индексации.
